# 🪔 શુભ દિપાવલી અને નૂતન વર્ષાભિનંદન • વિક્રમ સંવત ૨૦૮૧ (સાલ મુબારક)

દિવાળી અને બેસતા વર્ષ (વિક્રમ સંવત ૨૦૮૧) નિમિત્તે **Jada Prakash (જાડા પ્રકાશ)** તરફથી બનાવવામાં આવેલી એક અત્યંત સુંદર, લક્ઝરી, રોયલ અને ૧૦૦% મોબાઈલ-રિસ્પોન્સિવ ડિજિટલ ગ્રીટિંગ વેબસાઇટ. 

આ વેબસાઇટ ખાસ કરીને **WhatsApp પર શેર કરવા** અને **GitHub Pages પર ૧૦૦% મફતમાં લાઈવ કરવા** માટે તૈયાર કરવામાં આવી છે.

## ✨ આ વેબસાઇટની મુખ્ય વિશેષતાઓ (Key Features)

1. **દિવાળી અને બેસતા વર્ષની ભવ્ય થીમ (Diwali & Vikram Samvat 2081 Bestu Varas):**
   - સોનેરી આસોપાલવનું તોરણ (Golden Toran) - નેવબારની નીચે ક્લિયર લુક સાથે.
   - શુભ-લાભ, સ્વસ્તિક, મંગલ કળશ અને રંગોળી મોટિફ.
   - શુદ્ધ અને સુંદર ગુજરાતી ફોન્ટ્સ (*Hind Vadodara*) સાથે રોયલ ગોલ્ડન લુક.
   - "શુભ દિપાવલી અને નૂતન વર્ષાભિનંદન", "વિક્રમ સંવત ૨૦૮૧ સાલ મુબારક • બેસતું વર્ષ".

2. **🪔 ઇન્ટરેક્ટિવ દીવો પ્રગટાવો (Interactive Diya Lighting):**
   - વિઝિટર દીવા પર ક્લિક કરીને પોતાનો શુભ દીવો પ્રગટાવી શકે છે!
   - દીવો પ્રગટાવતાં જ દિવ્ય મંગલ નાદ, ફટાકડા અને સોનેરી ફૂલોની વર્ષા થાય છે.

3. **🎆 રિયલ ફટાકડા અને આતશબાજી (Canvas Fireworks & Crackers):**
   - સ્ક્રીન પર ગમે ત્યાં ટચ કરવાથી રોકેટ અને ફટાકડા ફૂટે છે.
   - મોબાઈલ બેટરી ફ્રેન્ડલી અને સુપર સ્મૂથ 60 FPS એનિમેશન.

4. **🎵 મંગલ ઉત્સવ સંગીત અને ચાઇમ્સ (Music & Chimes):**
   - બેકગ્રાઉન્ડ મ્યુઝિક ઓન/ઓફ કરવા માટે ફ્લોટિંગ બટન અને નેવબાર સાઉન્ડ પીલ.
   - મોબાઈલ માટે નીચે સ્પેશિયલ થમ્બ બાર.

5. **💌 ૩D સરપ્રાઈઝ રોયલ પરબિડીયું (Surprise 3D Envelope):**
   - વિક્રમ સંવત ૨૦૮૧ના રોયલ ગોલ્ડન સીલવાળું પરબિડીયું, ટચ કરવાથી ખુલે છે અને ગુપ્ત આશીર્વાદ પત્ર બહાર આવે છે.

6. **📲 ૧૦૦% મોબાઈલ ફ્રેન્ડલી (Mobile-First Hamburger & Thumb Bar):**
   - વર્કિંગ હેમ્બર્ગર ટોગલ મેનુ (☰ થી ✕) સ્મૂથ ડ્રોઅર સાથે.
   - મોબાઈલમાં નીચે ફ્લોટિંગ બાર: **દીવો પ્રગટાવો**, **મ્યુઝિક**, અને **WhatsApp શેર**.
   - એન્ડ્રોઇડ કે આઇફોનમાં કોઈપણ હેંગિંગ કે કટ થયા વગર પરફેક્ટ ડિસ્પ્લે.

7. **🌟 નામ સાથે પર્સનલાઇઝ લિંક (Personalized Name Links):**
   - ઉદાહરણ: `index.html?name=રાહુલ` અથવા `index.html?name=Priya`
   - જે પણ લિંક ખોલશે તેમનું નામ મુખ્ય બેનરમાં સુવર્ણ અક્ષરે દેખાશે!

   - સીધા WhatsApp પર સુંદર ગુજરાતી મેસેજ સાથે લિંક શેર થાય છે:

## 🚀 GitHub Pages પર ૧૦૦% મફતમાં લાઈવ કરવાની રીત (Step-by-Step)

### પગલું ૧: GitHub પર એકાઉન્ટ અને રિપોઝિટરી બનાવો
1. [GitHub.com](https://github.com/) ખોલો અને લોગિન કરો.
2. ઉપર જમણી બાજુ **+** બટન દબાવી **New repository** પસંદ કરો.
3. રિપોઝિટરીનું નામ આપો (દા.ત. `bestu-varas-2081` અથવા `sal-mubarak-2081`).
4. **Public** સિલેક્ટ રાખો (ફ્રી હોસ્ટિંગ માટે પબ્લિક હોવું જરૂરી છે).
5. **Create repository** બટન દબાવો.

### પગલું ૨: બધી ફાઈલો અપલોડ કરો
તમારા કોમ્પ્યુટરમાંથી આ ફોલ્ડરની બધી ફાઈલો અપલોડ કરો:
- `index.html` (રૂટ ફોલ્ડરમાં જ હોવી જોઈએ)
- `style.css`
- `script.js`
- `README.md`
- `assets/` ફોલ્ડર (જેમાં `assets/images` અને `assets/music` બંને છે)

*(GitHub પેજ પર "uploading an existing file" લિંક પર ક્લિક કરીને બધી ફાઈલ ખેંચીને મૂકી શકો છો)*.

### પગલું ૩: GitHub Pages ચાલુ કરો
1. તમારી રિપોઝિટરીના **Settings** ટેબમાં જાઓ.
2. ડાબી બાજુની મેનુમાં **Pages** પર ક્લિક કરો.
3. **Build and deployment** માં:
   - **Source:** `Deploy from a branch` પસંદ કરો.
   - **Branch:** `main` (અથવા `master`) અને ફોલ્ડર `/ (root)` પસંદ કરો.
4. **Save** બટન દબાવો.

### પગલું ૪: તમારી લાઈવ લિંક તૈયાર!
૩૦ થી ૬૦ સેકન્ડમાં તમારી લિંક તૈયાર થઈ જશે:
```text
https://<તમારું-યુઝરનેમ>.github.io/<રિપોઝિટરી-નામ>/
```
